# 文章暗号与图片排版

## 更新与部署

本次新增 PostgreSQL 表 `BlogAccess` 和 `BlogUnlockBudget`，不修改已有文章字段。
请先备份数据库，再运行：

```sh
docker compose --profile tools build app db-init
docker compose --profile tools run --rm db-init
docker compose up -d --force-recreate app
```

不要删除数据卷。表尚未创建时服务端将拒绝读取正文（不会把受保护内容当成公开内容）。

## 设置暗号

打开后台文章编辑页，顶部增加「需要暗号才能阅读」。
新文章先保存为草稿、设置暗号后再发布，避免正文短暂公开；已有文章可以开启保护、填写暗号、点击「保存暗号设置」。
此设置独立于正文保存，切换开关后须点击「保存暗号设置」才会生效。
开启后留空保留原暗号；输入新值替换；关闭后保存解除保护。

- 标题、列表、日期、标签及标题 SEO 仍可公开。正文需要输入暗号。
- 同一文章的所有语言版本共用暗号，不能通过切换语言绕过。
- 评论接口也检查解锁状态，防止从讨论内容绕过正文保护。
- 已登录管理员可在前台查看并在后台编辑，无需逐篇解锁。
- 暗号 4–128 个字符，区分大小写与空格。不写进 Markdown，不进入翻译提示词。
- 暗号只保存带随机盐的 scrypt 哈希，不回显明文。
- 正确输入后设置 HttpOnly、SameSite=Lax Cookie；HTTPS 站点使用 Secure。
- 解锁凭据有效期 12 小时，绑定文章 ID 和当前暗号版本。修改暗号使旧凭据失效。
- 每篇文章共用一个数据库尝试预算：10 分钟最多 30 次有效格式验证，跨进程生效。
  限流属于基础防暴力尝试，不是完整的 DDoS 防护。高访问量可在反向代理加访客级限流。
- 读取页面为动态渲染，正文 JSON API 和相关接口返回 private/no-store。
  CDN/Cloudflare 不应对文章页面或 `/api/*` 强制「缓存所有内容」。

### 保护边界

这不是端到端加密或 DRM：标题仍然公开，知道暗号的读者可以复制内容。
已经公开过的正文无法从第三方缓存、截图、浏览器历史或搜索引擎中撤回。
已有 `/media/...` 和外部图片地址仍是公开资源；此功能保护文章正文，
不把已公开的图片自动转成私有附件。敏感附件不要上传到现有公开图片桶。
开启模型翻译时正文仍会发送给管理员配置的模型提供商；暗号不会发送给模型。

## 图片不挤文字

原图片语法不变：

```md
![证件照|120px|float=right](/media/实际图片地址.webp)

## 你的姓名

个人介绍。

### 教育背景

学校和专业。
```

包含环绕图片的正文中，二至六级标题统一左对齐，避免照片旁的居中轴与下方不同。
文章独立的大标题保持原样。照片最多占正文宽度的 28%，与文字之间保持 1.5rem 间距。
实际正文/预览栏宽度不超过 34rem 时，照片改为独立一行，不再压缩旁边文字。
不含环绕图片的文章保留原有标题居中样式。
