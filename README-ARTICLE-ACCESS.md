# 文章暗号与图片排版

## 更新与部署

文章暗号使用 PostgreSQL 表 `BlogAccess` 和 `BlogUnlockBudget`；管理员创建的免暗号分享使用新表 `BlogShare`。
`BlogAccess.adminBypass` 默认 `false`，管理员免验证须在后台逐篇选择开启。
本次新增分享表，**即使之前已经创建过暗号表，也需要更新结构**。先备份数据库，再拉取代码并运行：

```sh
docker compose --profile tools build app db-init
docker compose --profile tools run --rm db-init
docker compose up -d --force-recreate app
```

不要删除数据卷。访问控制表或字段缺失时服务端拒绝读取受保护正文，不会把错误当成公开访问。

## 后台设置暗号和管理员免验证

位置：**后台 → 博客 → 编辑文章 → 文章暗号**。

- 「需要暗号才能阅读」控制该文章是否保护正文，标题始终公开。
- 「管理员免暗号验证」是每篇文章独立的选择性开关。
  - 关闭：包括管理员在内，前台正文、译文和评论均需有效解锁凭据；有效的管理员分享也可解锁。
  - 开启：已登录管理员可直接在前台查看；其他读者仍需暗号或有效分享。
  - 后台编辑和创建分享权限不受此开关影响，不会把管理员锁出管理页。
- 两个开关都必须点击「保存暗号设置」才生效。页面会显示已保存状态与未保存提示。
- 只修改管理员开关不需要重填暗号，也不会改写正文、清空暗号、触发翻译或让旧分享失效。

新文章先保存为草稿、设置暗号后再发布，避免正文短暂公开。
此设置独立于正文保存。首次开启须填写暗号；之后留空保持原暗号，输入新值替换，关闭保护并保存则解除保护。
旧客户端省略 `adminBypass` 时保留已有设置；新建默认关闭。

### 为什么没输入暗号也能看

请区分：保护开关尚未保存、当前管理员被允许免验证、浏览器仍有有效的暗号解锁记录、或读者持有有效的管理员分享。
关闭管理员免验证不会使已经合法取得的暗号或分享凭据失效。
测试未解锁效果请用无痕窗口打开**不带 code/share 的普通文章地址**。
修改暗号会使旧暗号解锁凭据以及旧分享失效；撤销单条分享只影响那一条分享。

## 管理员创建免暗号分享

文章已开启保护并发布后，在编辑页的「免暗号分享（仅管理员可创建）」中填写备注、选择有效期和打开语言，然后创建、复制链接。
**不再要求管理员重填原暗号，也不把原暗号写进新分享链接**。读者打开后自动向服务端验证令牌，通过后阅读正文。
可以单条撤销，有效期可选 1 小时、1 天、7 天、30 天。完整链接只显示一次，数据库只保存摘要。

权限检查、比对实现、生命周期和回归说明见 [管理员免暗号分享](README-ARTICLE-SHARES.md)。

### 旧版带暗号链接兼容

原有 `#code=…` 和手动拼接的 `?code=…` 仍按普通暗号验证。它们携带暗号本身，不是新的独立分享记录。
原后台暗号拼接界面已被免暗号分享管理替换；旧管理 POST 接口仍要求管理员权限与正确暗号，保留兼容。
新分享使用 `#share=…`，两种链接的凭据均在 POST 验证前从当前地址移除，普通章节锚点不受影响。
无论哪种链接，拿到完整链接的人都可能转发，请只给允许阅读的人。

## 验证与保护边界

- 标题、列表、日期、标签及标题 SEO 公开。未验证的正文不写入客户端 HTML/RSC 或 JSON。
- 同一文章的六种语言共用暗号与分享访问判断。评论接口也做访问检查，防止讨论内容绕过正文保护。
- 暗号 4–128 个字符，区分大小写与空格，不写入 Markdown 或翻译提示词；只保存带随机盐的 scrypt 哈希，不回显。
- 暗号验证后设置 HttpOnly、SameSite=Lax Cookie；HTTPS 站点使用 Secure。普通解锁凭据有效期 12 小时，绑定文章和暗号版本。
- 暗号验证使用每篇文章共享的数据库尝试预算：10 分钟最多 30 次有效格式验证，跨进程生效。
  这是基础防暴力尝试，不是完整 DDoS 防护，高访问量应在反向代理增加访客级限流。
- 独立分享 Cookie 与普通暗号 Cookie 分离，并在后续读取时查撤销/过期状态。
- 读取页面动态渲染，访问相关 JSON API 返回 private/no-store，CDN 不应对文章页面或 `/api/*` 强制缓存全部内容。
- `#` 片段不会随页面 GET 发送，但不是加密。查询参数第一次请求可能已被代理记录，清理地址无法撤回。
- 暗号保护不是端到端加密或 DRM，无法收回已经显示、复制、截图或被第三方缓存的正文。
- 已有 `/media/...` 与外部图片仍是公开资源，不会自动变成私有附件；敏感附件不要放在现有公开图片桶。
- 开启模型翻译时正文仍发送给管理员配置的模型提供商，暗号不发送给模型。

## 图片不挤文字

原图片语法不变：

```md
![证件照|120px|float=right](/media/实际图片地址.webp)

## 你的姓名

个人介绍。

### 教育背景

学校和专业。
```

包含环绕图片的正文中，二至六级标题统一左对齐，避免照片旁的居中轴与下方不同。
文章独立大标题保持原样。照片最多占正文宽度的 28%，与文字间距为 1.5rem。
正文或预览栏不超过 34rem 时，照片独立一行，不压缩旁边文字；没有环绕图片的文章保留原标题样式。
