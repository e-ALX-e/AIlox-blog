# 独立悬浮球

前台所有页面使用两颗同尺寸（48px）的 FluidOrb；不再在同一个面板中翻页。

- 蓝色球：快捷设置，保留背景音乐、仅显示背景、天空时间、云层控制和浅色/深色主题。
- 紫色球：全球时间，显示中国和洛杉矶的时间（精确到秒）、日期、星期和时区。
- 桌面默认在右下角竖向排列：蓝球距右、下边缘各 28px；紫球距右 28px、距下 104px，两球边缘间距 28px。
- 手机宽度不超过 480px 时，整体上移 56px，为底部阅读目录条留出单独一行；同时考虑设备安全区域。
- 两球可分别拖动，释放拖动不会误打开面板；打开面板期间暂时关闭该球拖动。
- 同时只打开一个面板。桌面优先在球左侧打开，窄屏向上打开，由 Base UI 处理边缘避让、关闭及焦点。
- 每个面板都有标准/液态玻璃切换，共用原来的浏览器偏好 `ailoxi:quick-menu:panel-style`，无需重设。
- 标准/液态玻璃切换不改变面板尺寸；小屏不足时只滚动内部内容。
- 洛杉矶使用 `America/Los_Angeles`，中国使用 `Asia/Shanghai`。使用设备当前时间和浏览器时区数据，不调用时间服务。
- 时钟关闭或标签页隐藏时不刷新，打开或恢复可见时重新读取当前时间。
- 普通刷新后恢复默认位置；不保存拖动坐标。没有数据库或依赖变更。

## 更新

拉取 main 后，按原流程重新构建 app 并重建容器即可。本次悬浮球改动无需执行 db-init。

```sh
docker compose build app && docker compose up -d --force-recreate app
```

此前的文章暗号版本有数据库升级要求；尚未应用的旧数据库升级不能因此跳过。

## 回归检查

安装项目开发依赖后：

```sh
node --test tests/floating-menus.test.cjs
pnpm ts:check
pnpm build
```

单元测试覆盖两球挂载/互斥、拖动点击隔离、原有设置操作、样式偏好、时钟刷新生命周期和夏令时/跨日。
测试使用框架适配器，不替代真实浏览器或完整 Next.js 构建。部署后检查桌面、手机横竖屏，
以及图文阅读页的底部目录条；拖动至视口边缘时弹窗仍应可见，键盘 Enter/Space 打开、Escape 关闭。
