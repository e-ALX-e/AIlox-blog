# 独立的暗号与分享管理页

## 入口与分区

后台导航新增「暗号与分享」：`/admin/blog-access`。
按标题或 slug 搜索，筛选全部、已设暗号、公开阅读或草稿，每页 20 篇。
点击文章进入 `/admin/blog-access/<文章ID>`。

详情页分为「暗号保护」和「免暗号分享」两个分区，不再同时堆叠：
- 暗号保护：保存开关、设置/修改暗号、选择管理员是否免验证。
- 免暗号分享：创建、复制独立令牌链接，查看有效期和状态，单条撤销。

切换分区保留未保存输入与当前生成的一次性分享链接；修改暗号设置后须先保存，才能继续管理分享。
关闭或刷新有未保存修改的页面会提示。离开页面前仍应保存设置并复制一次性链接。

文章编辑页不再加载权限表单和分享请求，只显示「管理暗号与分享 ↗」入口，
在新标签页打开对应文章，避免离开正在编写的正文。
新文章先保存为草稿，然后配置暗号，最后再发布。草稿可以设置暗号，但不能创建分享。

## 权限与数据

列表数据查询和详情页都在服务端验证管理员身份。列表只查询标题、slug、发布状态及权限标记；不查询正文、暗号哈希或分享令牌。
现有暗号、管理员免验证、分享创建/撤销接口及数据库结构不变。
读取失败不当作空列表或公开文章，并提供重试；标题仍公开，前台正文和各语言版本的服务端访问判断不变。

## 中文栏目名

前台简体中文「日志」改为「闲书」，繁体中文「日誌」改为「閒書」，浏览器栏目标题同步更新。
品牌命名在 `lib/i18n/site-messages.ts` 中覆盖；其他语言和原文章内容保持不变。
`/zh/blog`、`/zh-tw/blog` 和文章 slug 不变，不用重译文章。
