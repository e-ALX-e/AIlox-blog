# 管理员创建的免暗号分享

## 使用

后台 → 博客 → 编辑文章 → 文章暗号 → **免暗号分享（仅管理员可创建）**。
先保存文章暗号设置并发布文章。输入可选备注，选择打开语言和有效期，点击「创建免暗号分享」。
有效期有 1 小时、1 天、7 天（默认）、30 天；每篇文章最多 50 条同时有效的分享。
管理员不需要重新填写或知道已保存的文章暗号，前台「管理员免暗号验证」开关也不影响创建权限。

完整链接只在创建成功时显示一次，可立即复制；刷新后只能查看备注、创建时间、到期时间和状态，不能从哈希还原链接。
网络异常时先刷新列表检查是否已创建；丢失链接可撤销那条记录，重新创建。
同一篇文章可以给不同收件人分别建链接，分别撤销；链接仍可被收件人转发，不是实名绑定。

示例形状（下面不是可用的凭据）：

```text
https://www.example.com/zh/blog/sample#share=as1.<分享ID>.<随机令牌>
```

读者不必登录或输入暗号。浏览器先清理地址栏中的令牌，再 POST 到服务端验证；成功后设置独立的 HttpOnly 分享 Cookie 并刷新正文。
链接过期、被撤销、文章撤回发布或修改暗号后，不能靠原链接解锁。标题仍然公开。

## 服务端权限与比对

### 文章暗号

现有 `BlogAccess.codeHash` 不变：随机 16 字节盐 + scrypt（N=32768, r=8, p=3, 输出 32 字节），保存格式为 `s1:盐:哈希`。
校验时用存下来的盐重新计算输入值，再用 `timingSafeEqual` 比对；不是解密，也不把暗号明文或哈希返回给读者。
现有暗号尝试预算继续生效。

### 独立分享

- 创建、列出、撤销接口均在服务端检查当前登录者的管理员权限；不是仅在前端隐藏按钮。
- `POST /api/admin/blog-shares` 只使用服务器会话身份，不接受请求体指定创建人或访问权限。
- 使用随机 UUID 标识记录，另生成 32 字节（256 bit）随机秘密；它不由暗号、标题、文章编号或时间戳推算。
- 数据库 `BlogShare` 只保存带域区分的 SHA-256 令牌摘要；请求令牌重新计算摘要后用 `timingSafeEqual` 比较。
- 校验同时检查文章 ID、当前暗号版本指纹、有效期和撤销状态。管理列表不返回令牌、令牌哈希、暗号哈希或正文。
- 随机令牌采用快速摘要是因为本身具备高熵；用户选择的暗号仍使用慢哈希 scrypt，两者用途不同。
- 同一文章创建分享和修改暗号使用相同的文章行锁顺序，避免创建与关闭保护并发时生成脱离保护的记录。

公共 `POST /api/blog/[slug]/share` 只能兑换已存在的有效分享，不能创建分享记录。
校验成功签发 `sg1` 格式、HMAC-SHA256 签名的分享 Cookie，与原 `v1` 暗号 Cookie 分离。
分享会话最长 12 小时，而且不能超过分享链接本身的到期时间。超过会话时间、但链接仍有效时，可重新打开完整链接验证。

**每次受保护正文、译文、JSON 和评论请求都重新查分享是否有效。**
因此撤销后，之前兑换过的分享 Cookie 在后续服务端请求中也会被拒绝；不只是在兑换入口检查一次。
已经通过普通暗号解锁的人，或享有管理员免验证权限的人，仍保留其独立的访问方式。
分享不授予后台管理、文章修改或创建其他分享的权限；评论的原有登录、审核和删除权限不变。

## 生命周期及边界

- 修改暗号：旧分享的版本指纹不匹配，链接及分享 Cookie 失效；只改管理员免验证开关不影响分享。
- 关闭暗号保护：外键级联删除该文章的分享；重新开启不会复活原链接。
- 撤销单条分享：不影响其他独立分享。下一次服务端读取生效，不能收回已显示、复制或下载的内容。
- 发布状态、暗号保护和真实授权由服务端检查，不能通过换语言、改文章 ID、拼接 URL 或改 Cookie 绕过。
- 页面保持动态渲染，访问相关 API 使用 private/no-store。不要在 CDN 对文章页面、RSC 或 `/api/*` 强制缓存所有内容。
- 默认使用 `#share`，不在页面 GET 查询中传令牌；也兼容 `?share`，但首次 GET 可能已进入代理日志，不能事后撤回。
- 拒绝重复令牌以及 `share` 和 `code` 混用的歧义参数；正常章节锚点保留。
- 获得完整链接等于获得阅读凭据。片段不是加密，浏览器扩展、收件人或页面脚本仍可能看到；请勿公开贴链接。
- 这是文章正文访问控制，不是端到端加密或 DRM。原有公开媒体地址、外部附件、第三方缓存不会自动转为私有。
- 开启自动翻译时正文仍会发送给管理员配置的模型服务商。

旧版 `#code` 链接仍兼容原暗号验证；它携带的是暗号本身，并非可单条撤销的管理员分享。
后台不再使用旧的暗号拼接界面生成新分享。已掌握暗号的人可以告诉别人暗号，已获得分享的人也能转发完整链接。
“仅管理员创建”指只有管理员能签发、管理新的独立分享记录，不保证收件人不能转发。

## 部署

新增 `BlogShare` 表、外键与文章索引，没有增加依赖。先备份 PostgreSQL，拉取代码后：

```sh
docker compose --profile tools build app db-init
docker compose --profile tools run --rm db-init
docker compose up -d --force-recreate app
```

不要删除数据卷。未更新表结构时分享 API 返回错误，不能把异常视为验证通过。
