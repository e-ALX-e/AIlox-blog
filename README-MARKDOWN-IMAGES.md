# Markdown 图片布局

在原有图片尺寸语法后添加 `|float=right`，即可把图片放在正文右侧，让后面的文字环绕。添加 `|float=left` 则靠左。编辑器预览和文章阅读页使用同一套参数解析和样式，不需要开启原始 HTML。

## 证件照放在右上角

先粘贴或拖拽图片上传，保留返回的 `/media/...` 图片地址，再在图片说明中添加参数。下面的地址只是示例，需要换成实际上传地址：

```md
![证件照|120px|float=right](/media/blog/2026/09/photo.webp)

## 你的姓名

邮箱：your-email@example.com

### 教育背景

学校、专业和就读时间。

### 专业技能

在这里填写技能与个人介绍，文字会在照片旁边排版。

---

### 实习经历

分隔线以下恢复通栏排版。
```

把图片单独放一行，放在需要环绕的文字**前面**，中间空一行。这里用二级标题写姓名：站点原有的第一个一级标题会被提取成独立文章标题，不属于正文环绕区域。本功能不改变标题提取逻辑。

## 参数

| 参数 | 效果 |
| --- | --- |
| `120px` 或 `width=120px` | 指定宽度，像素范围为 64–2000 |
| `30%` 或 `width=30%` | 指定百分比宽度，范围为 10%–100% |
| `float=right` | 靠右，后续正文在左侧环绕 |
| `float=left` | 靠左，后续正文在右侧环绕 |
| `float=none` | 不环绕，恢复原来的居中展示 |
| `frame=none` | 取消显示容器的底色、内边距和圆角 |
| `frame=default` | 使用原来的图片展示容器 |

参数可以组合、顺序可交换。默认浮动图片不加展示底框，适合证件照；不传宽度时使用 120px。图片按原比例缩放，不裁切、不拉伸。

## 避免挤压文字

- 宽正文中浮动图片最多占**当前正文容器宽度的 28%**，与文字间保留 1.5rem 间距。
- 正文或编辑器预览栏不超过 **34rem** 时，图片独立成行，后续文字恢复全宽。不仅依据浏览器视口判断，也依据实际分栏宽度判断。
- 带环绕图片的正文中，二至六级标题统一左对齐，避免照片旁边的标题中心轴与下方标题不一致。独立的文章大标题保持原样。
- 普通非浮动图片不受 28% 限制；不含浮动图片的文章保持原有标题样式。

不浮动的旧图片语法保持兼容：

```md
![普通图片](/media/blog/example.webp)
![居中小图|60%](/media/blog/example.webp)
![居中固定宽度|600px](/media/blog/example.webp)
```

更多例子：

```md
![插图|30%|float=left](/media/blog/example.webp)
![带底框的小图|140px|float=right|frame=default](/media/blog/example.webp)
![不加底框的居中图|200px|frame=none](/media/blog/example.webp)
```

文字超过图片底部后自然恢复全宽。需要提前结束环绕时，单独写一行 `---`（上下都空一行）；代码块、表格与普通大图也会放在浮动图片下方。正文容器会包含浮动图片，避免照片越界到评论区。

这只是显示排版，不会改动上传文件。`frame=none` 不会去掉图片文件本身的白底。外部 Markdown 查看器不一定支持这些自定义参数。

## 维护

- `lib/core/markdown/image-size.ts`：校验布局参数，只接受白名单值。
- `lib/core/markdown/image-frame.ts`：预览和服务端共享的 HAST 图片装饰逻辑。
- `ui/(main)/blog/article-display-page/media.css`：共享样式。
- 参数解析发生在 HTML 清洗之后，生成的宽度仅来自经过范围校验的数字；不接受任意 CSS。

本地安装开发依赖后运行回归测试：

```sh
node --test tests/markdown-image-layout.test.cjs
```
